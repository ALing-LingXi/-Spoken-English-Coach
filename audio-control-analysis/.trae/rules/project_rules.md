# 项目规则

## 强制规则：完成 Task 后必须同步更新 tasks.md

**这是强制规则，不可跳过。** 每次完成一个 Task 的所有工作后，必须立即执行以下步骤更新 `.trae/specs/build-mvp-voice-chat/tasks.md`：

1. 将对应 Task 标题的状态标记从 🔴 改为 ✅
2. 将该 Task 下所有 SubTask 的复选框从 `[ ]` 改为 `[x]`
3. 更新底部"当前状态总结"：
   - 将该 Task 从"🔴 需要完成"表格移到"✅ 已完成"表格
   - 更新已完成和需要完成的计数

**验证**：更新完成后，必须用 Read 工具重新读取 tasks.md 确认修改生效。
